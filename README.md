# subchemica v0.1.1
An easy to use interpreter for chemists. The goal of this project is
to provide an
easy to use app for chemists to perform tasks that are often behind
a pay wall. SOme of these tasks include: predicting spectra, fitting data,
producing figures, analyzing data, and finding names of compounds.
Subchemica will always be free, open source, and availabel under the
MIT license. I hope you find this tool to be useful.

## Build
Subchemica can be built by running th ecompile script in the subchemica
directory(where this README also resides) or by running GNU make. 
You can ad flags to the
compile script to define what features you wish to include.
```
./compile <flags>
```
