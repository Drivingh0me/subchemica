# BUILD GUIDE
Build by running the bash script "compile"
```
./compile <flags>
```
Flags:
- __-d/--debug__ Debug build.
- __-l/lib__ The compiled program will not use dynamic linking to libraries.
- __-L/--Link__ Build without linking to any external libraries.
